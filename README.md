# Canard PC: l'IA ne répond plus (GameJamCanardPC2026)

Aidez vous de l'IA pour écrire un article à la rédaction de CanardPC.
Jeu fait pour la gamejam Canard PC 2026 [Make Something Horrible 2026 : to Slop or not to Slop](https://itch.io/jam/make-something-horrible-2026).

## Contrôles:
* ZQSD + souris: se déplacer
* Espace: Intéragis
* Esc: Quitter
* F1: options
